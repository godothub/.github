# GodotHub

![Annual G-Star](assets/annual_gstar_org.svg)

## 社区介绍

GodotHub是国内领先的游戏引擎社区，拥有包括公众号、论坛、桌面软件、微信/QQ/Discord社群在内的一系列平台，专为游戏创作者服务。作为国内Godot社区的代表，GodotHub一直致力于推动Godot游戏引擎在中国的广泛应用与深入发展。自2023年起，GodotHub每年举办一场开发大赛（[GodotHub Festival](https://godothub.com/event/festival-2026)），现已成为国内Godot游戏引擎社区规模最大的比赛。
